# Japolic — UI/UX Case Study

A brand and product UI design case study for **Japolic**, a fictional developer infrastructure company building a high-performance shared file system for AI and data-intensive workloads.

This project was created as a design assessment, covering brand direction, product UI design, and a design walkthrough.

## Overview

Japolic allows developers to connect multiple servers to shared storage and access data at speeds close to local disks, while integrating with S3 to keep frequently used data fast and less-used data cost-effectively tiered to cold storage.

The goal of this case study was to translate that technical concept into a visual identity and product interface that feels **classic, warm, trustworthy, technical, confident, and polished** — drawing on the character of early computing and engineering rather than typical dark-mode developer-tool aesthetics.

## What's Inside

### Brand Direction
- **Logo / wordmark** — a bold slab-serif wordmark
- **Color palette** — warm rust orange, cream, near-black, and deep forest green
- **Moodboard** — visual references grounded in vintage technical manuals, industrial signage, and early computing

### Product UI
- **Storage Overview Dashboard** — the primary screen, surfacing throughput, latency, hot/cold data split, connected servers, and a dataset view showing each volume's cache state (Hot vs. tiered to S3)
- **Connect a Server flow** — a three-step supporting interaction (name & identify → CLI-based connection → success state) designed around how developers actually set up infrastructure
